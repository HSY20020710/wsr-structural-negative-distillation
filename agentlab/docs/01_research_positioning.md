# Research Positioning

Welding Knowledge AgentLab is a supporting research workbench for the WSR-guided structural negative distillation pipeline.

It is designed to:

- expose the paper pipeline as inspectable agent/tool steps;
- record evidence for candidate extraction, WSR Gate decisions, and structural-negative construction;
- separate public demo execution from private paper experiments;
- avoid treating demo outputs as newly computed paper results.

The public release contains runnable demo code and synthetic examples only.
